# 战地 1 狙击枪弹道标尺（屏幕悬浮窗）

> phantomolithship 制作

## 文件

| 文件 | 作用 |
|---|---|
| `bf1_overlay.py` | 主程序，双击或命令行运行 |
| `bf1_weapons.json` | 全部 32 把侦察兵步枪的解包数据（初速 / 阻力 / 重力 / 存活时间 / 可用倍镜） |
| `settings.json` | 首次运行后自动生成，保存你的设置 |

## 使用

双击 `启动标尺.bat`（无控制台窗口），或命令行运行 `python bf1_overlay.py`。

要求：Windows，Python 3.8+（自带 tkinter，无需装任何库；导出 PNG 也是纯标准库实现）。

1. **游戏必须设为「无边框窗口」模式**（选项 → 影像 → 全屏模式），否则悬浮窗无法叠在游戏画面上。程序能自动检测你的显示模式并提示。
2. 启动程序后会弹出设置面板，全屏标尺在后台置顶显示；标尺窗口鼠标穿透，不会挡住你点游戏。
3. **点「从战地1配置读取FOV」**：程序自动读取 `文档\Battlefield 1\settings\PROFSAVE_profile`，填入步兵 FOV、载具 FOV、并核对游戏分辨率与显示模式。
4. 在设置面板选择：枪械 → 瞄准镜倍率 → 归零距离（和游戏内一致）。
5. 进游戏开镜，用刻度线对应距离的那一格瞄准即可（中心点是归零距离的命中点）。
6. **校准**：程序按「开镜 FOV = 基础 FOV ÷ 倍率」换算，个别倍镜可能有 1–3% 误差。去训练场对 300m 靶打几枪，如果弹着点稳定偏高/偏低，在设置面板微调「像素校准」百分比即可。
7. **导出标尺 PNG**：设置面板上的橙色按钮把当前武器的标尺按屏幕等大小渲染成透明 PNG（图片中心即屏幕中心，刻度位置与悬浮窗逐像素一致），保存到程序目录，可导入 Crosshair X 等准星工具使用。
8. 所有设置自动保存，下次启动直接生效。

注意：战地 1 的 FOV 设置项是**垂直 FOV**（程序已按此默认）；载具/炮位视角使用独立的「载具 FOV」（对应配置里的 FieldOfViewVerticalVehicle，默认 55）。

## 热键（游戏中切换）

| 热键 | 功能 |
|---|---|
| Ctrl+Alt+← / → | 上 / 下一把枪 |
| Ctrl+Alt+↑ | 循环归零距离（0 → 75 → 150 → 300） |
| Ctrl+Alt+↓ | 循环瞄准镜倍率 |
| Ctrl+Alt+H | 显示 / 隐藏标尺 |

## 弹道模型

- 阻力：BF1 引擎模型 dv/dt = −k·v²，k 为阻力系数
- 飞行时间 t(x) = (e^(k·x) − 1) / (k·v0)，下坠 = ½·g·t²
- 刻度偏角 = 精确解算命中目标距离所需仰角 − 归零距离仰角（数值求解落点方程，不是下坠量÷距离的近似）
- 像素换算：tan(偏角) ÷ tan(垂直FOV/2) × 半屏高，垂直FOV 由你的 FOV 设置、屏幕宽高比和倍率推出
- 狙击枪数据：sym.gg 解包的战地 1 官方武器文件（g = 12 m/s²）

## 载具/炮位模式

武器列表末尾的载具条目（野战炮 FK96、驱逐舰 QF4英寸速射炮、AT火箭炮）：

- **野战炮 FK96 (实测校准)**：v0 = 120.7 m/s，k = 0.002588，g = 7.0（2026-10-20 用户游戏内实测 7 组刻度-落点数据拟合，复现偏差 <5%，取代贴吧旧值 121.3/0.0012）
- **驱逐舰 QF4英寸速射炮 (实测校准)**：v0 = 281.5 m/s，k = 0.004674，g = 7.0，炮口高度 2.8m（同日为 6 组实测数据拟合，复现偏差 <3%）；100m/200m 刻度在准星上方属正常（近距离需俯瞄），最大落地射程约 645m
- 这类武器出膛速度只有步枪的几分之一，下坠极大，建议把「刻度间隔」设为 25m
- 载具/炮位没有倍镜（倍率固定 1.0x）、没有归零功能（归零固定 0），使用独立的「载具 FOV」
- 程序里 ttl 为子弹/炮弹存活时间，刻度不会超过物理上可达的溅落距离

## 说明

- 战地 1 的 FOV 设置项是**垂直 FOV**；屏幕分辨率程序自动读取，点「从战地1配置读取FOV」可同时核对游戏内分辨率（不一致会警告）。
- 标尺最大距离同时受「最大距离」设置和子弹/炮弹存活时间物理上限约束，信息栏会显示当前武器的实际最大射程。
- 开镜后画面中心的准星是游戏自带的，程序叠加的是中心点 + 下坠刻度 + 距离标注，不影响游戏文件，纯属外部叠加显示。
